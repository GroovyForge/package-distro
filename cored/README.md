# Cored for Android TV

Published Cored releases contain a signed APK, SHA-256 checksum, release metadata and a VirusTotal report link.

Update channel manifests are published under `channels/beta.json` and `channels/stable.json` when a release is ready. A missing channel means there is no advertised release for it.

APKs are GitHub Release assets, not files committed to this repository. The application source is maintained in a separate private repository.
